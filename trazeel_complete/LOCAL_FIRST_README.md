# Trazeel Local-First

Aplikasi ini menggunakan penyimpanan lokal pada browser/perangkat. Tidak ada Supabase atau autentikasi server.

Untuk panduan instalasi, akun lokal, Quick Switch, backup/pemulihan, dan mode offline, baca `README.md`.

Logo resmi aplikasi berada di `dashboard-trade/logo-trazeel.png` dan digunakan pada splash screen, welcome screen, header dashboard, favicon, serta ikon instalasi aplikasi.

Zoén terintegrasi pada navbar, tetapi seluruh file chatbot tetap terpisah di `dashboard-trade/zoen/`.
